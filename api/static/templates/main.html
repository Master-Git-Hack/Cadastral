0 Información del Metadato

La presente información ha sido elaborada por la Coordinación de Plataformas Geomáticas Catastrales siguiendo los lineamientos establecidos en la Norma Técnica para la elaboración de Metadatos Geográficos del INEGI. Esta información se refiere a los productos relacionados con la Cartografía Catastral, detallando aspectos como la fuente de origen, su ubicación en la base de datos, la extensión geográfica y el sistema de referencia utilizado. Todos estos elementos proporcionan un contexto adecuado para el uso eficiente de la información.
